# CLI Canon 0.1.6

## Summary

0.1.6 adds Canon-owned consumer CLI presentation compatibility so products can migrate incrementally without duplicating help, discovery, execution-result, or usage-failure projection logic.

## Changed

- Add bounded mixed-route descriptors with deterministic ownership checks for incremental migration.
- Add canonical help projection for summary, full, and JSON help surfaces.
- Add typed Node execution results with terminal stdout/stderr/exit-code projection.
- Add structured Commander usage-failure classification.
- Add discovery, overlap, runtime, packed API, and public type coverage for the new presentation compatibility surfaces.
- Preserve existing root, Node, and testing package exports.

## Install

```bash
npm install @yohn-jp/cli-canon@0.1.6 zod
```
