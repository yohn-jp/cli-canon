# CLI Canon 0.1.1

## Summary

0.1.1 is the first patch release of `@yohn-jp/cli-canon` after the 0.1.0 bootstrap release.

It adds the Canon-owned Node test TAP diagnostics projection used by downstream CLI tooling and adopts Prettier as the repository's canonical formatter.

## Added

- Node test TAP diagnostics support through `@yohn-jp/cli-canon/testing`.
- Generic TAP projection that preserves actionable failure diagnostics for downstream consumers.

## Changed

- Prettier is now the canonical repository formatter.
- `pnpm run verify` includes the canonical formatting check.

## Compatibility

This is a backward-compatible patch release from 0.1.0.

Node.js 24 or newer is required. Zod 4 remains a peer dependency.

## Install

```bash
npm install @yohn-jp/cli-canon@0.1.1 zod
```

## Release verification

Before publishing 0.1.1:

```bash
pnpm install --frozen-lockfile
pnpm run verify
pnpm pack
node scripts/smoke-test.mjs --tarball ./yohn-jp-cli-canon-0.1.1.tgz
```

Publish through the repository's canonical release workflow and create GitHub Release `v0.1.1` targeting the exact release commit.
