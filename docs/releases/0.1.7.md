# CLI Canon 0.1.7

## Summary

0.1.7 closes the remaining incremental-migration help-presentation gap found by the first Wabachi adoption of CLI Canon 0.1.6.

## Changed

- Add a typed `NodeCliTerminalAdapter.help` hook for consumer-specific terminal help presentation.
- Supply the adapter with Canon-resolved help mode/request and scoped discovery metadata so consumers do not parse help argv or Canon-rendered text.
- Preserve the existing default summary/full/JSON help output when no help adapter is configured.
- Keep mixed Canon/legacy route ownership and discovery composition under CLI Canon authority.
- Add runtime and packed public-type coverage for the help-presentation hook.
- Document the incremental-migration help adapter in the README.

## Compatibility

This is additive. Existing consumers that do not configure `terminalAdapter.help` retain the 0.1.6 help behavior.

## Install

```bash
npm install @yohn-jp/cli-canon@0.1.7 zod
```
