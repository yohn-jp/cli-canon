# CLI Canon 0.1.5

## Summary

0.1.5 supersedes the abandoned 0.1.4 release attempt.

The release aligns CLI Canon package metadata with the existing yohn-jp npm package contract so npm Trusted Publishing provenance can validate the source repository.

## Changed

- Add canonical `repository`, `homepage`, and `bugs` package metadata matching Inari, Wabachi, Nawabari, and Mottainai.
- Advance the package version to 0.1.5 because `v0.1.4` is immutable and abandoned.

## Install

```bash
npm install @yohn-jp/cli-canon@0.1.5 zod
```
