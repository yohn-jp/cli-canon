# CLI Canon 0.1.3

## Summary

0.1.3 supersedes the abandoned 0.1.2 release attempt.

The release adds the `tsx` development runtime required by the organization-wide npm release certification contract. The shared release workflow remains unchanged, preserving compatibility with existing consumers.

## Changed

- Add `tsx` as a development dependency for release certification.
- Advance the package version to 0.1.3 because `v0.1.2` is immutable and abandoned.

## Included since 0.1.0

- Node test TAP diagnostics support through `@yohn-jp/cli-canon/testing`.
- Generic TAP projection preserving actionable assertion diagnostics.
- Prettier as the canonical repository formatter.
- Self-contained runtime tests that build their required `dist` artifacts.

## Compatibility

This is a backward-compatible patch release from 0.1.0.

Node.js 24 or newer is required. Zod 4 remains a peer dependency.

## Install

```bash
npm install @yohn-jp/cli-canon@0.1.3 zod
```
