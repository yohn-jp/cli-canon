# CLI Canon 0.1.4

## Summary

0.1.4 supersedes the abandoned 0.1.3 release attempt.

The release aligns CLI Canon with the existing organization release consumers by allowing the `esbuild` install script required by the `tsx` certification runtime.

## Changed

- Allow the `esbuild` native build used by `tsx` through `pnpm-workspace.yaml`.
- Advance the package version to 0.1.4 because `v0.1.3` is immutable and abandoned.

## Install

```bash
npm install @yohn-jp/cli-canon@0.1.4 zod
```
