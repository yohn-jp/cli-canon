# CLI Canon 0.1.2

## Summary

0.1.2 supersedes the unpublished 0.1.1 release attempt.

The release keeps the existing built-runtime certification intact while making `pnpm test` self-contained for the shared npm release workflow. Runtime tests require compiled `dist` artifacts, so the test script now builds before executing them.

## Changed

- `pnpm test` now runs `pnpm run build` before the runtime test suite.
- Package version advanced to 0.1.2 because the immutable `v0.1.1` release attempt is abandoned.

## Included since 0.1.0

- Node test TAP diagnostics support through `@yohn-jp/cli-canon/testing`.
- Generic TAP projection preserving actionable assertion diagnostics.
- Prettier as the canonical repository formatter.

## Compatibility

This is a backward-compatible patch release from 0.1.0.

Node.js 24 or newer is required. Zod 4 remains a peer dependency.

## Install

```bash
npm install @yohn-jp/cli-canon@0.1.2 zod
```

## Release verification

Before publishing 0.1.2:

```bash
pnpm install --frozen-lockfile
pnpm run verify
pnpm pack
node scripts/smoke-test.mjs --tarball ./yohn-jp-cli-canon-0.1.2.tgz
```

Publish through the repository's canonical release workflow and create GitHub Release `v0.1.2` targeting the exact release commit.
